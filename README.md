# Hope Mobile

An Expo React Native app for browsing uplifting news stories on your computer and testing directly on an iPhone with Expo Go.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the Expo dev server:

```bash
npm run start
```

3. Test on your iPhone:

- Install Expo Go from the App Store.
- Make sure your iPhone and this computer are on the same Wi-Fi network.
- Scan the QR code shown in the terminal or Expo browser page.

If your network blocks local discovery, use:

```bash
npm run start:tunnel
```

## Other commands

```bash
npm run ios
npm run android
npm run web
```
